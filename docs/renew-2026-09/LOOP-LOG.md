## 2周目 ループ1（03:02〜03:25）全幅の検品・読み込みの重さ・キーボード

見た物: 上の4つの道具を全幅で。768 / 390 / 320 / 1920 は全体を等倍で通し見

見つけた物と直した事
1. 読み込みが重い: 4G 相当で load まで 44秒、転送 7.2MB。フォントの先読みが 249本（Shippori Mincho の字の範囲ごとのファイル全部。トップでは使っていない）。オープニングは load を待つので、スマホではローディングが 8秒（待ちの上限）出たままになっていた。→ layout の Shippori Mincho を preload: false に。load 6.1秒、転送 1.1MB。見た目は変わらない（使うページでは今までどおり読み込む）
2. 768px（タブレット）でヘッダーのメニューが「毎月の／流れ」「ALPACAに／ついて」と2段に折れていた。1rem が下限の 10px に張り付くので、PC の並びが入り切らない。→ 1023px 以下はハンバーガーに
3. 768px で料金カード3枚が1枚 190px になり、「月／15万円〜」と折れ、3枚目が白いパネルの外に切れていた。→ 768〜1023px は1列にして絵を左に置く横長のカード。PC の3列も minmax(0,1fr) に
4. 768px で理由カード3枚が ±5° の傾きで互いに重なっていた。→ 傾いても隣に届かない幅（21rem・すき間 4rem）に
5. 768px でフッターの申込ボタンのメールが「alpaca.amami@gmail.c／om」と折れていた。→「@」の前でだけ折れるように
6. ページに h1 が無かった。→ ヒーローの「会社の仕事に、AIの手を。」を h1 に（白い幕の上の同じ文は飾りのまま）
7. PC でメニューに Tab で入るとパネルが開き、メニューを抜けても開いたままで、ページ全体が 50% 暗いまま最後まで Tab が進んでいた。→ メニューとパネルの外へフォーカスが出たら閉じる。Esc でも閉じる
8. フッターで隠れた横の導線が、見えないのに Tab で止まっていた。→ 消え終わったら visibility: hidden
