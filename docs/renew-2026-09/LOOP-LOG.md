## ループ1（01:51〜02:12）作って最初の見比べ

見た物: PC 1440 のオープニング 0〜3秒、PC のスクロール位置 0/1200/2100/3300/4700/5700、スマホ 390 のオープニング

ずれていた所と直した事
1. LOADING... の文字: お手本は表示直後から1文字ずつ弾むが、こちらは JS（GSAP）が動くまで止まっていて、t=300ms で「LOA」まで。→ #1 を CSS の keyframes に移し、elastic.out(1.2,0.6) を GSAP の式から 40点の linear() に写して同じ加速にした。#2 の波だけ GSAP に残した
2. ボタンや CTA の文字色: `.tp a { color: inherit }` が強すぎて、下の大きな申込ボタンのメール欄が黒地に黒で消えていた。→ `:where(.tp) a` に下げた
3. フッター上の帯がフッター写真の下に潜っていた。→ 帯を z-index 3 に
4. ヒーローの小見出しが「ひとつず／つ」で折れていた。→ 句で3つに分けて inline-block、全体に word-break: auto-phrase
5. 学校紹介に当たる「毎月の流れ」の写真枠がお手本より横長で大きかった。→ 52rem×50rem の写真＋40rem の文字に（お手本は写真の方が縦に近い）
6. ギャラリーの上のイラストがお手本より大きく見えた。→ 23rem → 20rem、下揃え
7. タブレット幅（768〜1023px）で PC の寸法のままだとはみ出す所（理由カード3枚・バナー2枚・流れのブロック）を縮める指定を足した

合っていた所
- オープニングの時間の流れ: スマホで t=2000ms に丸い穴が開き始め、2200ms で半分、2400ms で開き切る、がお手本と同じコマで起きている
- 英字の大見出し（Reason）が、着いてから 200ms の時点で「Rea」まで弾んでいる所がお手本と同じ
- 毎月の流れのブロック: 着いてから 400ms で半透明、700ms で出切る、がお手本の学校紹介と同じ
- 各セクションの縦の位置（PC）: ヒーロー 881px（お手本 881）、帯 706（711）、困りごと 919（925）、AI顧問とは 1235（1235）、ギャラリー 1711（1670）、料金 2476（2515）

## ループ3（02:22〜02:31）触った時の動き・2回目の訪問・動きを減らす設定・セクション同士の見比べ
