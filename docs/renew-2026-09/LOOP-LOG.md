## ループ8（02:52〜02:56）Safari（WebKit）で見る

見た物: Playwright の WebKit で、スマホ 390 と PC 1440 のオープニングと全体を撮った。値は Chromium と同じ（1rem = 10.4px / 11.08px、横はみ出しなし、エラーなし）

1. WebKit は word-break: auto-phrase が効かず、「話してみ／る」「ありませ／ん」のように言葉の途中で折れていた。→ 文を「、」「。」「／」「）」「」」の後ろと「（」の前で区切って、かたまりごとに折り返す小さな関数（phrase.tsx の ph）を作り、困りごと・AI顧問とは・料金の中身・バナー・理由カード・流れ・ALPACAについて・よくある質問の答え・申込ボタンに使った

3. 料金の行「月15万円〜（定例の打ち合わせ月1回）〜 月25万円（月2回）」が「月／1回）」で折れていた。→「（」の前でも切る

合っていた所

- 1rem の計算、:has() での大きさの切り替え、@property の補間、linear() の ease は WebKit でも効いている
