## 描き直しの指示: ヒーロー（S01〜S03）とフッター（H01）の人物の位置（3周目に実測）

3周目の測り方: 3120 の本番ビルドで、白い文字・ボタン・帯・固定の導線が元の絵（1672×941 / 1925×817）のどこに乗るかを、object-fit: cover の切り抜きを戻して元の絵の % で出した（scratchpad r3/zones.mjs）。今は字の下に薄い帯と影を入れて読めるようにしてあるが、顔に字が被るのは絵でしか直せない

### ヒーロー（PC は 16:9 の横長 1枚）
| 何が乗るか | 元の絵の位置（横 x・縦 y） |
|---|---|
| 見える範囲 | 1920 幅: x 4〜96%／1440: x 7〜93%／1024: x 15〜85%／768: x 24〜76%。縦はほぼ全部 |
| キャッチ「会社の仕事に、AIの手を。」 | x 15〜85%、y 33〜53%（1024 以下は2行で x 29〜71%、y 27〜58%） |
| 小見出し | x 24〜76%、y 49〜66% |
| ボタン「まずは30分、話してみる」 | x 37〜63%、y 64〜72% |
| 流れる帯（#AMAMI など）と波の切り抜き | y 76% より下は全部隠れる |
| ヘッダー（右上）・横の導線（右端） | x 46〜90% の y 14% より上、x 89% より右の y 26〜71% |

- 字が横に 15〜85% まで広がるので、「顔を左右の外側 30% に」では足りない。1024 幅では外側 15% が切れて見えない
- 描き方: **y 25〜62% の帯の、x 12〜88% には顔を置かない**（空・海・窓・壁など、細かい物が少ない中くらいの明るさの面）。**人物は顔（頭の上から顎まで）を y 60〜75% に**。横は **x 16〜34% と x 66〜84%** の2か所に分け、ボタンの x 37〜63% を空ける。胴から下は y 76% より下で帯に隠れてよい（今の S03 の2人が近い。S03 は字が顔に被っていない）
- 人物の大きさ: 頭の高さが絵の縦の 8〜11%（1440 幅で 75〜100px）。今の S01・S02 は頭が縦の 20% 近くあって字の帯に入る
- 色: 字の帯（y 25〜62%）は白い字が浮く中くらい〜少し暗めのミント・青緑。真っ白な雲や白い壁を字の真後ろに置かない
