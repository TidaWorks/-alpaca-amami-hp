# 後で差し込む絵の枠の一覧

作る時の決まり: フラットの公式パカ君（151番、docs/image-recipes/parent-pakakun-sheetA.png を --ref）、色はミント・黄・墨＋白が主。お手本の絵や写真は参考にしない。新しい画像は WebP
ページ上の枠: `data-slot="ID"` の要素。中に薄く「画像: ○○」と書いてある。差し込む時は `Slot` に `src` を渡すだけで、大きさと動きはそのまま残る（src/components/top/Slot.tsx）
大きさは実測の表示サイズ（PC 1440 幅 / スマホ 390 幅、px）。画像は表示の2〜3倍で作る
